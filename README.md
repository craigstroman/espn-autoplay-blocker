# ESPN Auto Play Blocker Chrome Extension

This is a Chrome extension that will block videos embedded in articles from auto playing when you load the page.

## Install Instructions

- git clone https://github.com/craigstroman/espn-autoplay-blocker.git
- Looad Chrome and then open Extensions by clicking on Window, then Extensions
- Click to enable 'Developer Mode'
- Click on 'Load Unpacked' extension and select the extension you just downloaded.
